# FLEETIQ website
Static bilingual (RO/EN) website for the FLEETIQ project. Development-stage statements are intentionally explicit. No backend, cookies for tracking, third-party fonts or external assets.

## Publish via GitHub Pages
1. Create a public GitHub repository, e.g. `fleetiq-site`.
2. Upload `index.html`, `privacy.html`, `style.css`, `script.js` to repository root.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Visit `https://YOUR_USERNAME.github.io/fleetiq-site/` after deployment.

## Before sharing the website in a commercial application form
- Replace the contact placeholder with a working professional email.
- Confirm product statements and update the project status.
- Complete a real privacy policy for the Android app before using it as a Play Store privacy policy; the included notice is NOT a complete app privacy policy.
- Do not claim OpenAI approval or integration is active until verified.
